# 🥢 三餐指南 - 智能饮食规划

基于《中国居民膳食指南（2022）》的 AI 智能饮食规划工具。

## 特性

- **AI 智能菜单生成**：接入大语言模型，基于膳食指南生成一周菜单
- **隐私优先**：用户 API Key 仅存储在浏览器本地，所有数据不上传
- **离线可用**：PWA 支持，首次加载后可在无网络环境下使用
- **膳食指南内核**：内置中国居民膳食指南八大准则、膳食宝塔、营养计算
- **完整功能**：周计划生成、烹饪卡片、购物清单、口味偏好、饮食画像
- **本地菜谱库**：内置 80+ 道结构化家常菜谱，支持搜索
- **手机 + 电脑自适应**：响应式设计，移动端触屏优化，桌面端宽屏展示

## 快速开始

### 方式一：直接打开

用浏览器打开 `index.html` 即可使用。

### 方式二：本地服务器（推荐）

```bash
# 使用 Python
python -m http.server 8080

# 或使用 Node.js
npx serve .
```

然后访问 `http://localhost:8080`

## 使用方法

1. **设置饮食画像**：首次打开点击「开始设置」，填写基本信息、饮食目标、做饭条件
2. **生成菜单**：点击「生成菜单」，系统会根据膳食指南 + AI 生成一周菜单
3. **查看菜谱**：点击任意菜品查看烹饪卡片（做法步骤、食材、营养信息）
4. **采购清单**：自动聚合所有食材生成分类采购清单，可勾选已购
5. **替换菜品**：不喜欢某道菜可以点「换一个」

## AI 功能（可选）

输入你的 AI API Key 以启用智能菜单生成：

1. 点击底部「我的」→「AI 密钥管理」
2. 输入你的 API Key（支持 OpenAI 兼容接口）
3. 密钥仅存储在浏览器 localStorage，不经过任何中间服务器

支持自定义 API 端点和模型名称。

## 膳食指南数据源

- 《中国居民膳食指南（2022）》八准则
- 中国居民平衡膳食宝塔（2022）
- 《中国居民膳食营养素参考摄入量》
- Mifflin-St Jeor 基础代谢率公式

## 隐私声明

- **所有数据存储在浏览器本地**，不上传任何服务器
- API Key 使用 Base64 编码存储在 localStorage
- AI 请求直接从浏览器发往 API 提供商，不经过中间代理
- 无追踪、无广告、无数据收集
