# 全日健康

> 从早到晚，都安排好了。饮食 · 运动 · 睡眠 · 心理 · 规划
>
> 一个人完整的一天，一个 App 全安排好。纯前端，零数据上传。

## 快速开始

```bash

# 浏览器打开 http://localhost:3111
```

或直接访问：https://hvrrgfe.github.io/quanri-jiankang/

## 技术架构

纯前端，零服务器成本。

```
html + css / js /
├── data/         数据库（食谱/运动/心理量表80+/睡眠/体态）
├── engine/       引擎（营养/运动处方/AI健康/时间线）
├── components/   视图组件（首页/饮食/运动/睡眠/心理/自测）
├── storage/      本地存储（localStorage + AES-256加密）
└── utils/        工具函数 + SVG图标库(77个)
```
