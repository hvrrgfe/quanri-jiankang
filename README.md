# 全日健康

> 吃 · 动 · 坐 · 睡 · 心 · 事
>
> 一个人的完整一天，一个 App 全安排好。

从早到晚，都安排好了。

---

## 六大模块

| 模块 | 功能 | 状态 |
|:----:|------|:----:|
| 🥢 饮食 | 基于膳食指南的 AI 饮食规划 | ✅ 已实现 |
| 🏃 运动 | 运动处方 + 动作库 + 运动计划 | ✅ 数据库就绪 |
| 💺 体态 | 久坐提醒 + 微运动 + 办公室解救 | ✅ 数据库就绪 |
| 🌙 睡眠 | 睡眠卫生 + 环境优化 + 时型适配 | ✅ 数据库就绪 |
| 🧠 心理 | 每日心理微练习（非医疗化） | ✅ 数据库就绪 |
| 📋 计划 | 每天 3 件事 · 反 GTD 宽松计划 | ✅ 数据库就绪 |


## 数据来源

所有数据基于权威研究与大学课程：

| 模块 | 数据来源 |
|------|----------|
| 饮食 | 中国居民膳食指南2025、DRIs 2023、WHO |
| 运动 | ACSM Guidelines 12th Ed (2025)、北京体育大学运动处方、WHO体力活动指南 |
| 体态 | OSHA办公人体工学、Stanford EHS、2025-2026久坐研究前沿 |
| 睡眠 | National Sleep Foundation 2025、AASM、2025-2026睡眠环境研究 |
| 心理 | 哈佛大学积极心理学(Tal Ben-Shahar)、CBT、Emmons感恩研究、4-7-8呼吸法(SFU 2023) |
| 计划 | MIT 3 Tasks Method(The Personal MBA)、帕金森定律实证(Peters 1984, Kamma 2013) |

## 技术架构

纯前端应用，无服务器、无数据库、不上云。

```
html + css / js /
├── data/         数据库（食谱/运动/体态/睡眠/心理/计划/价格）
├── engine/       引擎（营养/膳食指南/运动处方/时间线）
├── components/   视图组件
├── storage/      本地存储（localStorage + AES-256加密）
└── utils/        工具函数 + SVG图标库
```

## 隐私

所有数据仅存在你自己的浏览器里。不上传任何服务器。
