## 🚀 快速启动(手机端优先)


- **离线安装**:iOS Safari「分享 → 添加到主屏幕」,安卓 Chrome「安装应用」;Service Worker 已缓存全部资源,断网可用

## 核心功能

### 饮食管理
- **AI 周计划**：基于《中国居民膳食指南 (2025)》，结合用户档案生成一周菜单
- **本地引擎**：无 API Key 时自动降级，基于 158 道菜谱、膳食宝塔和营养计算生成
- **158 道菜谱库**：含食材、步骤、营养信息、烹饪时间、价格估算
- **采购清单**：自动生成，分品类，支持勾选购买状态
- **膳食合规检查**：13 项硬约束（食材多样性、深色蔬菜、红肉总量、鱼虾次数等）
- **备菜模式 / 家庭模式**：批量备菜方案、多人份量调整
- **自定义菜谱**

### 运动管理
- **AI 周计划**：基于中国全民健身指南 + ACSM 运动处方标准
- **7 种训练体系**：PPL、上下肢分化、全身训练、徒手训练等
- **55 种动作库**：含分步指导、难度、目标肌群、MET 值
- **心率分区**：基于 Karvonen 公式
- **运动打卡 + 7 天日历**
- **体重追踪**：30 天折线图 + 体脂率记录

### 睡眠管理
- 入睡/起床时间记录（原生 Time Picker）
- 五星质量评分 + 每周统计
- 科学睡前清单（NSF 指南）
- 时型匹配

### 心理健康
- 呼吸引导动画（4-7-8 / 盒式 / 4-4-6）
- 今日意图 + 感恩练习
- CBT 认知工具：10 种认知扭曲识别

## 人格测试（学术级）

基于 **IPIP-NEO-300**（International Personality Item Pool），心理学界使用最广泛的开源人格题库。

### 规格对比

| 指标 | 快速版 (60题) | 完整版 (300题) |
|------|-------------|--------------|
| 测试时间 | ~10 分钟 | ~50 分钟 |
| 每维度题数 | 12 | 60 |
| facets 覆盖 | 无 | **30 个**（每维度 6 个） |
| 正反平衡 | 6F + 6R | **5F + 5R / facet** |
| 维度信度 | α ≈ 0.80 | **α ≈ 0.87–0.92** |

### 五维度结构

| 维度 | 大五映射 | 6 facets |
|------|---------|----------|
| **Mind** 外向/内向 | 外向性 Extraversion | 友善·合群·果断·活跃·寻求刺激·积极情绪 |
| **Energy** 直觉/实感 | 开放性 Openness | 想象力·审美·情感·冒险·思辨·自由 |
| **Nature** 理性/情感 | 宜人性·反向 | 信任·正直·利他·合作·谦逊·同情 |
| **Tactics** 判断/感知 | 尽责性 Conscientiousness | 自我效能·条理·尽责·进取·自律·审慎 |
| **Identity** 坚定/波动 | 神经质·反向 | 焦虑·愤怒·抑郁·自我意识·冲动·脆弱 |

### 评分与解读

- **IRT 加权评分**：区分度权重 (1.0–3.0) + 95% 置信区间
- **CTT 经典测量理论**：原始分 + 百分比
- **中国常模**：王孟成等 (2010) N=4,359，分年龄/性别百分位
- **32 种类型×7 段深度解读**：身份定位·核心优势·潜在短板·职业方向·关系模式·成长建议·职场风格
- **30 个 facet 分数条形图** + 最强/弱特质高亮
- **SVG 雷达图** + 历史趋势折线图
- **类型确定度** + 次优匹配提示
- **他评模式**：生成表单 → 他评 → 自评/他评对比
- **效度检测**：4 组一致性校验 + 答题时间 + 社会赞许偏差 + 疲劳检测

### 学术引用

- Goldberg (1999). *IPIP*.
- Johnson (2014). *Journal of Research in Personality*, 51, 78–89.
- McCrae & Terracciano (2005). *JPSP*, 88(3), 547–561.
- 王孟成等 (2010). *中国临床心理学杂志*, 18(5), 545–548.

## AI 智能分析

通过 OpenAI 兼容接口调用大语言模型，对测评结果进行深度分析。

### 功能
- **心理测评 AI 分析**：任意量表 → 专业解读（总体解读·维度分析·建议·注意事项）
- **MBTI 深度分析**：IRT + 30 facet + 常模 → 5 段报告（画像·动力·盲区·人际·成长）
- **AI 对话追问**：分析结果可连续提问
- **AI 饮食/运动/作息/健康评估**：基于用户档案 + 专业指南

零一万物 / 百川智能 / 硅基流动 / Groq / Together / Ollama 本地

## 数据隐私

- **数据导入导出**：JSON 格式备份
